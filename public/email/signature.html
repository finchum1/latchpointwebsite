  1. Gmail: Settings (gear) → See all settings → General → Signature → Create new → paste → Save changes at the bottom.
  2. Apple Mail: Settings → Signatures → add one, paste, and untick "Always match my default message font."
  3. Outlook (desktop): File → Options → Mail → Signatures → New, then paste.
  4. Outlook (web): Settings → Accounts → Signatures → New signature, then paste.
  5. Anything that takes raw HTML: use Copy as HTML code.
  6. About the animation: Gmail, Apple Mail, and most phones play it on a loop. Outlook for Windows shows only the first frame, which is the complete logo, so it still looks right there.
